# Security Policy

## Supported versions

Security fixes are applied to the `main` branch.

## Reporting a vulnerability

Please do not open public GitHub issues for security vulnerabilities.

Report vulnerabilities by email to: info@kino.wtf

Include:

- A clear description of the issue
- Steps to reproduce
- Expected impact
- Any suggested remediation

You will receive an acknowledgment as soon as possible, and we will work with you on coordinated disclosure.
